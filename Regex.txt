# 🧠 1. What is Regex (1 line for exam)

👉 A **pattern used to validate or match text input**

---

# 🔤 2. Basic Building Blocks (MUST KNOW)

### ✔ Character sets

```javascript
[a-z]      // lowercase letters
[A-Z]      // uppercase letters
[0-9]      // digits
[a-zA-Z]   // letters only
[a-zA-Z0-9] // letters + numbers
```

---

### ✔ Special symbols

```javascript
^   // start of string
$   // end of string
.   // any character
```

---

### ✔ Length controls

```javascript
{5}     // exactly 5 chars
{5,}    // at least 5
{5,10}  // between 5 and 10
```

---

### ✔ Shortcuts

```javascript
\d   // digit (same as [0-9])
\w   // letter + number + _
\s   // space
```

---

# 🚀 3. MOST IMPORTANT PATTERNS (Exam Use)

---

# 🔥 1. Username Validation

👉 Only letters + numbers, min 5 chars

```javascript
let pattern = /^[a-zA-Z0-9]{5,}$/;
```

---

# 🔥 2. Password (Basic)

👉 At least 8 characters

```javascript
let pattern = /^.{8,}$/;
```

---

# 🔥 3. Password (Strong – VERY IMPORTANT)

👉 Must contain:

* 1 uppercase
* 1 lowercase
* 1 digit
* min 8 chars

```javascript
let pattern = /^(?=.*[a-z])(?=.*[A-Z])(?=.*\d).{8,}$/;
```

👉 ⭐ High chance in exam

---

# 🔥 4. Email Validation

```javascript
let pattern = /^[^ ]+@[^ ]+\.[a-z]{2,3}$/;
```

✔ Covers most exam cases

---

# 🔥 5. Phone Number (10 digits)

```javascript
let pattern = /^[0-9]{10}$/;
```

---

# 🔥 6. Only Alphabets

```javascript
let pattern = /^[a-zA-Z]+$/;
```

---

# 🔥 7. Only Numbers

```javascript
let pattern = /^[0-9]+$/;
```

---

# 🔥 8. Alphanumeric (no special chars)

```javascript
let pattern = /^[a-zA-Z0-9]+$/;
```

---

# 🔥 9. Name with spaces allowed

```javascript
let pattern = /^[a-zA-Z ]+$/;
```

---

# 🔥 10. Starts with letter

```javascript
let pattern = /^[a-zA-Z][a-zA-Z0-9]*$/;
```

---

# 🧠 4. How to Use in JS (IMPORTANT)

```javascript
if(!pattern.test(input)) {
    alert("Invalid input");
}
```

---

# 🔥 5. Full Example (Exam Ready)

```javascript
function validate() {

    let user = document.getElementById("user").value;

    let pattern = /^[a-zA-Z0-9]{5,}$/;

    if(!pattern.test(user)) {
        alert("Invalid username");
        return false;
    }

    return true;
}
```

❌ Writing wrong length
❌ Not using `.test()`
